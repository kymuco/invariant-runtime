# Support

Invariant Runtime is a pre-1.0 Python library maintained as an open-source project. Community help is best-effort; no guaranteed response time, paid support plan, or compatibility SLA is offered.

For routine questions, reproducible bugs, docs problems or feature proposals, use [GitHub Issues](https://github.com/kymuco/invariant-runtime/issues). Please check the [Getting started](docs/getting-started.md), [Public API](docs/reference/public-api.md), [Project status](docs/project/status.md) and existing issues first.

Provide the Python version, operating system, package/commit version, minimal reproduction and sanitized error output. Avoid sending credentials, user data, secrets, or private repository content.

For **security vulnerabilities**, use the private path in [SECURITY.md](SECURITY.md), not a public issue.

Plugin authors should remember that capability policies govern the capability API, not arbitrary untrusted Python code. See [Security](SECURITY.md) before accepting third-party plugins.
